# Ficha diaria CEC Race 26

Sistema de entrenamiento y asistencia para el equipo de esquí, con:
- Registro diario de entrenamiento (disciplina, nieve, clima, trabajo realizado, fundamentos, curvas)
- Asistencia por integrante, cruzada con las sesiones de su categoría
- Fichas médicas y teléfono de contacto por integrante
- Porcentajes por integrante (disciplina, nieve, clima, trabajo, fundamentos)
- Códigos de acceso por rol (jefe de entrenadores + una categoría por entrenador)
- Botón para compartir el resumen del día por WhatsApp
- Exportación a Excel

Los datos se guardan en una base de datos de Supabase (no en el navegador), por lo que se sincronizan entre todos los dispositivos que abran esta página.

## Cómo publicarlo
Sube este repositorio a Netlify (New site from Git) o a GitHub Pages, y usa `index.html` como página principal.
